Nao tentar ranquear tudo com uma unica home.

## Como transformar keywords em formatos de pagina

### 1. Landing page comercial

Usar quando a query indica compra ou comparacao direta.

Exemplos:
- `software para clinica odontologica`
- `sistema para clinica medica`
- `software para clinicas`

Estrutura ideal:
- resposta curta no topo
- para quem serve
- recursos
- comparativo
- FAQ
- CTA

### 2. Artigo comercial-informativo

Usar quando a query indica avaliacao ou duvida.

Exemplos:
- `melhor software para clinicas`
- `programa para consultorio medico`
- `software para odontologia`

Estrutura ideal:
- resposta inicial curta
- criterios
- erros comuns
- tabela
- recomendacao final
- link para landing

### 3. Comparativo com concorrente

Usar quando a query ja mostra comparacao ou marca.

Exemplos:
- `sistema feegow`
- `odontoclinic sistema`
- `sistema shosp`

Estrutura ideal:
- quem deve considerar migracao
- diferencas praticas
- tabela comparativa
- limites reais
- CTA

### 4. FAQ / glossario / definicao

Usar para ampliar presenca em IA e featured snippets.

Exemplos:
- diferenca entre sistema e software para clinica
- o que e prontuario eletronico
- o que e software medico online

## Regras para evitar canibalizacao

1. Cada landing principal deve ter uma keyword central.
2. Variacoes semanticas devem aparecer dentro da pagina, nao necessariamente como nova URL.
3. Criar nova URL apenas quando houver mudanca real de intencao.

Exemplo bom:
- `/sistema-para-dentistas`
- `/software-para-clinicas-odontologicas`

Exemplo ruim:
- criar 5 paginas quase iguais so trocando `software`, `sistema`, `programa`

## Regras para aproveitar melhor o GEO

1. Comecar cada pagina com uma resposta direta de 2 a 4 frases.
2. Incluir secoes com titulos em formato de pergunta.
3. Usar listas e tabelas em vez de texto corrido quando a resposta for comparativa.
4. Explicar claramente para quem o produto serve e para quem nao serve.
5. Citar limitacoes reais do sistema quando houver, porque isso aumenta confianca e citabilidade.
6. Manter consistencia de nomes e promessas em todas as paginas.
